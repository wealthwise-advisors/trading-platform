Signing in

Use your username and password, or one of the four provider buttons.

Signing in with X (Twitter) has one extra step. X does not share an email address at any scope, so after you authorise the app it asks you to choose a username and give an address. Finish that form and you are in — it is the last step, not an error. The link it hands you is single-use and expires after twenty minutes, so complete it in one go.
Forgotten password

Use Forgot password? on the sign-in page. A reset link is sent to the address on the account. It works once and expires; request another if it lapses.

Forgotten username

Use Forgot username?. Your username is sent to the address on the account.

Neither form ever reveals whether an address is registered. That is deliberate — an honest answer there would let anyone test which addresses hold accounts.

No email arriving
  • Check the spam folder first.
  • Confirm the address is the one the account was created with.
  • Provider sign-ins (Google, LinkedIn, GitHub) have no password, so there is nothing to reset — use the button instead.
A provider button says it is not connected

That provider has no credentials configured on the server. Use your username and password, or another button.

Running a backtest

Set the data source, symbol, timeframe and strategy in the left panel, then press Run Backtest. Results open beside it: equity curve, trade log, P&L distribution and pattern analysis.

Results are hypothetical. A backtest replays rules over bars that have already happened. It is not a prediction, and it is not advice. See the Terms of Service.
