### **A futures research platform that turns raw market data into scored, reproducible results — and admits when it doesn't know.**

</div>

<br>

## ⚡ In One Minute

Load market data → run a strategy over it → simulate fills the way a broker
would → score the result. Through a **browser**, a **CLI**, or a **bar-by-bar
replay**.

```bash
git clone https://github.com/wealthwise-advisors/trading-platform
cd trading-platform && pip install -r requirements.txt
py -3.12 scripts/run_backtest.py --symbol ES --strategy ma --fast 9 --slow 21
```

Real ES futures data ships with the repo. **No broker account, no API key, no signup.**

## 🎯 Why This Repository Is Interesting

<table>
<tr>
<td width="50%" valign="top">

### ⏳ No look-ahead, enforced

Orders fill on the **next** bar's open — never the signal bar. Every pivot
carries both the bar where the extreme occurred *and* the later bar that
confirmed it.

Tests truncate history mid-series and assert that nothing appears before it
could have been known.

</td>
<td width="50%" valign="top">

### 🎯 "Unknown" is a first-class result

The Elliott Wave engine can return **`UNDECIDABLE`** and name the open question
that blocked it.

There is no confidence score anywhere in the codebase — the source material
does not support one, so inventing one would be dishonest.

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 📓 27 open questions, tracked in public

Where the reference is ambiguous, the gap is **catalogued rather than
smoothed over**: 6 resolved, 20 unresolved, 1 confirmed not implementable.

Unevaluated rules are reported at runtime through
`AnalysisResult.blocked_rules`.

</td>
<td width="50%" valign="top">

### 🛡️ Guard tests against invention

A dedicated test class fails the build if any blocked rule is quietly
implemented with a made-up threshold.

The safeguard is **narrowed**, never deleted, when a concept genuinely becomes
measurable.

</td>
</tr>
</table>

## 🔍 Deep Dive

<details>
<summary><b>📡 Data Layer</b> — 4 providers, one interface</summary>

<br>

Swap the source and nothing downstream changes.

| Provider | Source | Notes |
|---|---|---|
| [`SchwabDataProvider`](src/data/schwab_provider.py) | Schwab API | OAuth2, 30-min token auto-refresh, 30-day request chunking |
| [`RithmicDataProvider`](src/data/rithmic_provider.py) | Rithmic R\|API+ | Native bar periods, resamples for 1h |
| [`ExternalCSVProvider`](src/data/external_csv_provider.py) | Local archive | Year-file aware, resamples from 1-minute source |
| [`CSVDataProvider`](src/data/csv_provider.py) | Project CSVs | `timestamp,open,high,low,close,volume` layout |

Plus [`sample_data.py`](src/data/sample_data.py) — a seeded GBM generator with
regime shifts. Not a provider, but it is what the test suite runs on, and it is
deterministic.

Committed real data lives in [`data/sample/`](data/sample) — 1-minute ES, GC,
BTC, NVDA, TSLA and AAPL bars, ~1.6 MB total. Contract specifications per
instrument (tick size, tick value, point value, margin) are in
[`config/settings.yaml`](config/settings.yaml).

</details>

<details>
<summary><b>🌊 Elliott Wave Engine</b> — 13 modules, and the reason this repo exists</summary>

<br>

Built from scratch against a single approved reference, in
[`src/analysis/elliott_wave/`](src/analysis/elliott_wave).

**Structures** — Impulse · Leading Diagonal · Ending Diagonal · Zigzag · Flat ·
Running Flat · Double Three · Triple Three

| Design decision | Rationale |
|---|---|
| **Purpose-built pivot detector** | Threshold-based directional change across a multi-scale ladder, deliberately independent of the existing swing/zigzag code so the two cannot silently couple |
| **`UNDECIDABLE` lifecycle state** | `ENUMERATED → GATED → MEASURED`, plus `UNDECIDABLE`. There is no `INVALID` state and no confidence score |
| **Blocked-rule registry** | Every unevaluated rule is disclosed at runtime with the open question behind it, so a partial analysis never reads as a complete one |
| **Measure, don't classify** | Triangles, extensions and Fibonacci ratios are *recorded* as measurements. They do not gate a classification, because the reference never defines the thresholds that would justify it |
| **Guard tests** | Assert that no blocked rule has been quietly implemented with an invented threshold |

**Open questions: 27 catalogued — 6 resolved · 20 unresolved · 1 not implementable.**

The unresolved ones are not TODOs. They are places where the reference is silent
and no defensible threshold could be derived from the data — tested against
shift nulls, empirical nulls and bootstrap mode stability before abstaining.

📄 [Rule inventory](docs/ELLIOTT_WAVE_RULES.md) ·
[Requirements](docs/ELLIOTT_WAVE_SRS.md) ·
[Architecture](docs/ELLIOTT_WAVE_ARCHITECTURE.md) ·
[Implementation record](docs/ELLIOTT_WAVE_IMPLEMENTATION.md)

<details>
<summary><b>♟️ Strategy Engine</b> — 5 strategies, zero UI wiring</summary>

<br>

Implement `on_bar()`, register the class, and the dashboard picks it up
automatically through [`strategy_registry.py`](api/strategy_registry.py).

| Strategy | Signal logic | Module |
|---|---|---|
| 🔍 **RSI Divergence** | Price/RSI divergence *arms* a setup; a close beyond the divergence bar *confirms* entry | [`rsi_divergence.py`](src/strategies/rsi_divergence.py) |
| 📊 **MA Crossover** | Fast EMA crossing slow EMA | [`ma_crossover.py`](src/strategies/ma_crossover.py) |
| 🚀 **Breakout** | Donchian channel break with ATR trailing stop | [`breakout.py`](src/strategies/breakout.py) |
| ↩️ **Mean Reversion** | RSI oversold/overbought reversion | [`rsi_mean_reversion.py`](src/strategies/rsi_mean_reversion.py) |
| 🧭 **Regime Adaptive** | Switches behaviour on the detected market regime | [`regime_adaptive.py`](src/strategies/regime_adaptive.py) |

**RSI Divergence** is the primary research line — a two-step pre-condition /
post-condition entry rather than acting on divergence alone.

</details>

<details>
<summary><b>🧪 Backtesting & Execution</b> — fills, engines, metrics</summary>

<br>

**Order model** — [`paper_broker.py`](src/broker/paper_broker.py)

| Order | Fill rule |
|---|---|
| Market | Next bar's open ± slippage |
| Limit | Fills when the bar's low/high crosses the limit price |
| Stop | Triggers when price crosses the stop level |

**Engines**

| Engine | Behaviour | Module |
|---|---|---|
| 🧪 Backtest | Runs the full range, returns complete results | [`engine.py`](src/backtesting/engine.py) |
| 🔄 Replay | `step()` returns one `FrameState` per bar, streamed over WebSocket | [`replay_engine.py`](src/backtesting/replay_engine.py) |
| 💵 Paper Broker | Simulated fills behind the same interface a live broker implements | [`paper_broker.py`](src/broker/paper_broker.py) |

Session filtering trims bars to trading hours *after* load and *before* signals
run, so out-of-session bars can never produce a signal.

**Metrics** — [`metrics.py`](src/backtesting/metrics.py) · [`results.py`](src/backtesting/results.py)

| Group | Measures |
|---|---|
| Risk-adjusted | Sharpe ratio · Sortino ratio · profit factor |
| Drawdown | max drawdown % · equity curve |
| Outcome | win rate · total return % · average win / loss |
| Behaviour | average trade duration · per-trade P&L with entry/exit prices, times, commission |

Plus [`trade_quality.py`](src/backtesting/trade_quality.py) scoring and a
parameter sweep at [`optimize.py`](api/routers/optimize.py).

</details>

## 🚀 Running It

**Requirements** — Python 3.12 · Node 18+

```bash
# Backend — http://localhost:8000
py -3.12 -m pip install -r requirements.txt
py -3.12 -m uvicorn api.main:app --reload --port 8000

# Frontend — http://localhost:5173, proxies /api/* to the backend
cd web && npm install && npm run dev
```

```bash
# CLI backtest, no UI
py -3.12 scripts/run_backtest.py --symbol ES --strategy ma --fast 9 --slow 21

# Point any run at the committed real data
#   config/settings.yaml →  data.external_dir: "data/sample"

# Tests
py -3.12 -m pytest tests/ -v
```

```bash
# Or the whole stack — API on :8000, dashboard on :8080
docker compose up
```

> Synthetic data and the committed samples both work with no credentials. Copy
> [`.env.example`](.env.example) to `.env` only for the optional live
> integrations it documents.
